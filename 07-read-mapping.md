# 07 Read mapping and coverage

> **Estimated time:** 60 minutes

---

# Biological question

> **How well does the assembly represent the original sequencing data?**

After assembly we want to know whether the reconstructed contigs explain most of the sequencing reads.

To answer this question, we align the original reads back to the assembly.

---

# Why map reads?

Read mapping serves several purposes.

It allows us to

- evaluate assembly quality;
- calculate sequencing depth;
- estimate contig abundance;
- generate coverage profiles used during genome binning.

Coverage becomes one of the strongest signals for separating genomes.

---

# Building the index

Before reads can be aligned, BBMap (https://bbmap.org/docs/guides/bbmapguide) builds an index of the assembled contigs.

```bash
cd megahit_out
bbmap.sh ref=final.contigs.fa
```

# Mapping reads*
*(note that we point to the reads that are now 1 folder up using the ../ ; see Unix Bash cheat sheets for tips/tricks f. example: https://devhints.io/bash)

```bash
bbmap.sh \
    in=../read1.fq \
    in2=../read2.fq \
    out=megahit.sam \
    bamscript=sam2bam.sh \
    threads=2
```

The resulting alignments are stored in SAM format.

Because SAM files are very large, they are normally converted to compressed BAM files. 
Inspect the bamscript that is generated by bbmap to understand what it will do. More explanation can be found on the samtools page.
https://www.htslib.org/doc/samtools.html

```bash
more ./sam2bam.sh
./sam2bam.sh
```

# Mapping statistics

Calculate mapping statistics

```bash
samtools flagstat megahit_sorted.bam
```

Important questions include

- What proportion of reads mapped?
- How many read pairs aligned properly?
- How many reads remained unmapped?

---

```{note}
Environmental soil metagenomes often show mapping rates below 30%.

Highly complex microbial communities are much harder to assemble completely than simple mock communities.
```

# Coverage

Next we calculate per-contig coverage.

> [!NOTE]
> **Sequencing coverage and depth: what do they mean?**
>
> **Read depth** is the number of reads overlapping a particular base.
> **Average coverage**, also called *fold coverage*, is the average depth
> across a genome or target region. The terms “coverage” and “depth”
> are often used interchangeably, so specify which measure you mean.
>
> **Breadth of coverage** is the percentage of bases covered by at least
> one read, or by a specified minimum depth, such as ≥10 reads.
>
> **Calculating average coverage**
>
> C = (N × L) / G
>
> - **C** = average coverage (e.g. 30×)
> - **N** = total number of individual reads
> - **L** = average read length in base pairs
> - **G** = genome or target-region size in base pairs
>
> **Example:** 500 million reads × 150 bp = 75 billion sequenced bases.
> For a 3-billion-base genome, average coverage is 75 / 3 = **25×**.
>
> For paired-end sequencing, count both mates: 250 million read pairs
> of 2 × 150 bp correspond to 500 million individual reads.
>
> This is a theoretical average. Actual depth varies across the genome,
> and some reads may be filtered out or fail to align.
> To measure depth and breadth, align reads to the reference and
> calculate coverage from the resulting alignment.


```bash
pileup.sh \
    in=megahit_sorted.bam \
    out=cov.txt
```

Inspect the cov.txt file. What are the different columns, which one do we need to obtain the per-contig abundance? 
To convert to a compatible abundance table for later we use the below code generating abundance.txt.

```bash
cut -f1,2 cov.txt \
| grep -v '^#' \
> abundance.txt
```

## Under the hood (optional)

Coverage reflects how many sequencing reads align to a particular genomic position.

Organisms with high abundance in the community therefore tend to produce contigs with higher coverage than rare organisms.

Genome binning algorithms make extensive use of this property.

---

## Biological takeaway

Coverage provides quantitative information about microbial abundance and becomes an essential feature for reconstructing genomes.
